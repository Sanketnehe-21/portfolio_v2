# 3D Model Attribution

This project uses geometry from:

- **Title:** Superman's upper body portrait
- **Author:** [IITheDarkness94II](https://sketchfab.com/IITheDarkness94II)
- **Source:** https://sketchfab.com/3d-models/supermans-upper-body-portrait-d53894716d184be7883ef0bf669e799a
- **License:** [CC-BY-4.0](http://creativecommons.org/licenses/by/4.0/)

The static mesh (`public/models/human.glb`) was packed from `scene.gltf` / `scene.bin` with node rotation transforms baked into static vertex coordinates and normals, and compressed using Meshopt (`gltfpack -c -vp 12 -vn 8`).
